# Каталоги Vicon Toshkent

Сайты: https://qwertyspacon.github.io/vicon/apteki/ · /igrushki/ · /tovary/

Остатки и цены берутся из Linko (только чтение) 3 раза в день (07:07, 12:07, 17:07 по Ташкенту) — `.github/workflows/update.yml` → `ci.py`.
Токен Linko хранится в секрете репозитория `LINKO_TOKEN`. Запустить вручную: вкладка Actions → «Обновление каталогов из Linko» → Run workflow.
